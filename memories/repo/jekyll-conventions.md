# Jekyll Conventions

## Setup

- Theme: `minima`, configured in `_config.yml`.
- Site source: repository root.
- Data source: `_data/*.yml`.
- Main custom stylesheet: `assets/css/style.scss`, with front matter and `@import '{{ site.theme }}';`.

## Front Matter

Top-level content pages preserve this shape:

```yaml
---
layout: page
title: Page Title
permalink: /page-slug/
---
```

The home page is intentionally minimal:

```yaml
---
layout: default
---
```

Keep front matter intact when editing page content.

## Links And Paths

- Internal page links are root-relative: `/publications/`, `/projects/`, `/contact/`.
- Static downloads use `/files/...`, for example `/files/cv.pdf`.
- Images use root-relative paths, for example `/images/profile.jpeg`.
- Publication anchors use `bibtex_key`: `/publications/#{{ paper.bibtex_key }}`.
- Project anchors use `id`: `/projects/#{{ project.id }}`.
- DOI links are generated from the bare DOI field in `_data/pubs.yml`.

## Liquid And Markdown

- Pages often mix Markdown, HTML, and Liquid.
- `publications.md` builds citation strings from `_data/pubs.yml`; avoid hand-editing publication lists in the page body.
- `projects.md` renders cards from `_data/projects.yml`; avoid duplicating project entries in Markdown.
- `research.md` uses `site.data.home.research_interests` for research-area cards.
- Homepage sections live in `_includes/home/`; update includes only when changing rendering behavior, not ordinary content.

## Styling

- Customize site styles in `assets/css/style.scss`.
- Existing style system uses CSS custom properties under `:root`, including `--color-ink`, `--color-heading`, `--color-body`, `--color-accent`, `--color-border`, `--color-surface`, and spacing/shadow variables.
- Typography uses Georgia for headings/site title and Segoe UI/Roboto/Arial for body text.
- Layout classes already in use include `home-section`, `home-section-header`, `home-list`, `home-list-item`, `home-publication`, `project-grid`, `project-card`, `page-card`, and `page-link-grid`.
- Prefer extending existing classes and variables over adding isolated one-off styles.

## Gotchas

- Do not edit `_site/`; it is generated by Jekyll.
- Homepage selected publications currently come only from `journal_papers`, even though `conference_papers` may also have `featured: true`.
- `preprints` currently exists as an empty top-level list, while `publications.md` also expects `working_papers` and `other_publications` if populated later.
- YAML strings with colons, apostrophes, non-ASCII names, or HTML should be quoted.
- Keep `authors` as a YAML list; publication rendering joins authors automatically.
- Keep `bibtex_key` and project `id` stable because they form public anchors.
- Generated links assume root-relative deployment on GitHub Pages, so avoid relative paths like `../files/...`.
